# 中国大陆城市目录

规范数据为 [mainland-cities.json](mainland-cities.json)，Go通过embed读取；KMP和Web副本由 [sync_city_catalog.py](../../scripts/sync_city_catalog.py) 派生。默认执行只读检查，显式 `--write` 才同步。运行不依赖地理数据接口或定位权限。

来源：[AreaCity-JsSpider-StatsGov 2025.251231.260403](https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov/releases/tag/2025.251231.260403)，2026-04-03发布，整合2025年底国家地名信息库及地图数据；许可为 [MIT](LICENSE)。下载的两个原始压缩包SHA-256保存在metadata中。仅提取区划名称、层级、拼音与GCJ-02浏览视野中心，不保留边界多边形或乡镇。

- 31个大陆省级地区，745个可选项：4个直辖市、293个地级市、397个县级市，以及40个自治州／盟／地区、11个省直辖县／林区。统计用重复层级按完整名称去重，重庆城区／郊县合并到重庆市。不包含港澳台及国外。
- `code`为6位区划代码；`name`为完整名称；`value`只去掉城市名末尾的“市”，保留既有武汉／上海等存储和规则键。自治州等保留完整名称。县级市显示所属地级和省级，独立选择；不与上级城市合并。
- 完整名称、既有短名、区划代码和来源中不冲突的别名可查找同一城市。未知历史字符串只做首尾空白清理，不按包含、拼音近似或随意去后缀猜城市。
- 服务端同城筛选、群目录、提醒与预约／协议城市核对共用此目录。城市规则可为目录中的任一项单独录入；仍核对运营权限、物种、允许行为、有效期限和版本。城市可选不代表业务自动开放，未核定城市继续关闭对应操作，不从省或地级自动继承县级市准入。
- 地图中心只控制浏览视野，不写入求助、订阅或选点；未知城市／未选择时用大陆概览，不能兜底武汉或伪造发生点。

这是明确版本的离线快照，不是实时行政区划服务。来源注明和康县、和安县尚缺地图数据；二者不是新增城市，不影响694座城市覆盖。后续城市调整需先更新规范目录及metadata，再同步派生副本。无本次构建、测试或设备验收证据。
