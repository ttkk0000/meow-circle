# 移动端字体来源

2026-10-22 从 Google Fonts 官方仓库下载原始可变字体，未修改字体文件。

- Noto Sans SC：`https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf`，授权见 `noto_sans_sc-OFL.txt`。
- Manrope：`https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf`，授权见 `manrope-OFL.txt`。

默认浅色客户端正文使用 Noto Sans SC，品牌使用 Manrope；字体及授权随应用打包。未覆盖旧端 Inter／Outfit 资源。
