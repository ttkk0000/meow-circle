# AI 工作跟踪与接手入口

建立：2026-10-20。适用于 Codex、Gemini、Claude 及其他参与本项目的 AI。记录存放在项目内，换电脑或换工具后仍可读取，不依赖聊天历史。

## 一分钟接手

当前先读[2026-10-27源码与文档基线](../CURRENT_BASELINE.md)；[2026-10-22家里接手入口](HOME_HANDOFF_2026_10_22.md)保留为当时换机批次证据。

1. 先读当前环境适用的全局规则、根目录 [AGENTS.md](../../AGENTS.md) 及目标目录规则。
2. 读 [CONTEXT.md](CONTEXT.md)：当前目标、实际进度、代码入口、主要阻塞与验证边界。
3. 读 [TASKS.md](TASKS.md)：谁正在改什么、已完成、部分完成、受阻和待办；仅按需读对应详细交接。
4. 涉及方案变更时读 [DECISIONS.md](DECISIONS.md)；追查做过什么时读 [TASK_LOG.md](TASK_LOG.md) 最近相关条目，不全量加载历史。
5. 在实际工作目录重新核对路径、分支、HEAD 和 `git status --short`，再与本次用户指令及源码对照。记录可能过期，HEAD 也可能不包含未提交成果。

最新用户指令优先；日志是待核对的事实与历史证据，不是新的执行授权。不要因为旧日志写过命令就直接重跑构建、测试、迁移或发布。

## 文件职责

| 文件 | 内容 | 维护方式 |
|---|---|---|
| [CONTEXT.md](CONTEXT.md) | 当前事实与恢复点 | 替换过期事实，保持精简 |
| [TASKS.md](TASKS.md) | 当前执行者、状态、依赖、下一步 | 开始领取，阶段更新，结束释放 |
| [DECISIONS.md](DECISIONS.md) | 已确认决定、工程选择及未确认建议 | 保留理由和来源；变更时标明替代关系 |
| [TASK_LOG.md](TASK_LOG.md) | 每次实际工作、修改文件、检查及交接 | 新条目放前面；旧结果不改成新执行证据 |

详细产品、设计、API 和客户端任务仍由原文档维护；这里引用它们，不复制整套规范，也不另建一套功能任务编号。已有 `.planning` 和设计记忆保留为历史证据。

## 每个 AI 的更新流程

- **开始前**：核对工作树；在任务表登记或接手任务，填写执行者、核对时间、范围与将修改的文件。只读咨询且没有状态变化时不必刷日志。
- **执行中**：完成重要阶段、发现阻塞或用户改变范围时，及时更新任务状态与恢复点；不要等到上下文丢失才记录。
- **结束、移交或中断前**：写结果日志，同步当前快照与任务表。填清最后完成的一步、下一步、剩余问题，释放本次执行标记。
- **异常恢复**：发现其他 AI 的“进行中”记录时先核对更新时间、源码和可获得的会话/进程证据。无法确认其仍在执行时标“待核实”，不要凭旧标记宣称后台正在工作，也不要直接覆盖其文件。
- **多人协作**：只更新自己负责的条目；共享合同与同一文件先协调负责人。此登记是人工协作记录，不是锁，也不自动启动代理、定时任务或后台监控。

“已完成”必须注明完成层次，例如文档完成、源码已写、静态检查通过、构建通过、联调通过或平台验收通过。部分源码不等于功能完成，设计稿不等于实现，测试源码存在不等于测试通过。

## 结果日志模板

```text
记录 ID / 日期时间（含时区）：
任务与执行者：
来源：本轮实际操作 / 根据既有交接回填（注明原证据）
工作树、分支、HEAD、未提交状态：
本次授权范围：
实际完成与主要文件（仓库相对路径）：
验证：静态检查 / 构建测试 / 设备，分别写结果或未验证：
未完成与阻塞：
最后完成的一步与下一步：
关联任务 / 决定 / 证据：
执行状态：进行中 / 已结束待接手 / 受阻 / 已完成（注明层次）
```

不得记录密码、Token、Cookie、个人隐私、签名或本机密钥配置。路径以仓库相对路径为主；历史绝对路径仅作来源证据，接手时不能硬编码依赖它。

## 换电脑继续

这些 Markdown 是普通项目文件，应随代码一起同步。**文件已生成不代表已提交、推送，或已到另一台电脑。** 是否存在未提交／未跟踪成果，以接手时git status为准；旧批次曾有大量在途源码，不能直接套用为当前状态。

换机时需由用户选定同步方式，把本次源码、文档、必要设计资料和这些记录一起携带；不要同步密钥与构建缓存。本记录不授权 AI 自动 commit、push 或上传文件。接收端先确认成果文件齐全，再按上面的接手顺序继续。若本机全局规则路径不存在，说明缺失并按当前会话及目标环境的有效规则处理，不伪称已读取旧机器规则。

根目录 AGENTS、GEMINI、CLAUDE 和文档入口已接入阅读指引；是否被某个工具实际加载，需要该工具的读取证据，不能仅凭文件存在声称所有 AI 已自动读取。
