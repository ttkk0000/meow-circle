## 手机样式怎样延续

- 显式沿用 `Mobile Light V2`（`56:0`）及既有浅中性背景、珊瑚主动作、Noto Sans SC / Manrope、16 圆角卡片和 48 高胶囊动作，没有创建另一套配色。
- 按钮、字段、图标、社交卡、宠物照片与表情来自现有文件；只补跨端导航、大屏宠物卡和可伸缩布局组件。原有手机组件未被修改。
- 导航保持社区／领养／发布／消息／我的的任务含义。走失互助保留为上下文入口，未增加交易或后台导航。
- Web 内容区最大 1248；桌面常驻侧导航，消息在空间足够时显示会话／聊天／宠物上下文三栏。
- 平板基准为 834×1194 与 1194×834。竖屏消息收起第三栏，横屏领养展开主从；744 宽详情退回单页阅读，底部保留主要动作。已有方向对应页面的导航优先保留方向，其他参考仍可能跳到另一方向画板，不能当作实际旋转适配。
- 发布保留图文与局部上传失败；横屏平板另展示表情区域。该画板需要滚动查看完整区域，不是实机键盘避让证明。

## 业务和隐私边界

游客可以阅读，登录成功后续接申请；取消返回上下文。手机号、微信和 QQ 是固定设计入口，没有执行授权。需要主动确认的提交默认不可提交；申请、私密线索先看摘要。

预约保留 V2 当前生效、V1 历史、恢复旧时间需提出 V3 的规则。私密材料不进入公开发布；普通群成员不出现群主管理操作。离线草稿明确“本机未同步”，没有承诺真实跨设备同步。

输入、筛选、重试、系统授权、发送和提交不是实际服务。部分按钮只用于固定参考画板导航，不模拟任意输入或真实账号状态；不能按可点击数量推断业务实现完整度。

## 验证结果

- 56 个精确根 ID 均存在、非空、无占位，均显式使用手机浅色模式。
- 原生文字与组件层为主体；仅离散宠物照片使用图片填充，没有整屏截图作为交付层。
- 全部文字使用 Noto Sans SC / Manrope，未发现缺失字体。
- 最终自动布局盒检查未发现水平／垂直越界；有意滚动内容和 SVG 内部路径坐标不按普通盒模型误判。
- 代表页已目视复核；修复手机卡片固定内部宽度、筛选文字换行、平板互助入口和小图标边界。
- 导航目标存在且属于对应页面。未逐条点击原型，也没有进行设备、读屏、系统键盘或动态输入验证。

最终回读见 [静态核对账本](cross-platform-light-validation.json)。未运行编译和测试，遵循全局不自行编译规则。

本地静态检查：10 个新增资料文件 UTF-8 无 BOM，4 个 JSON 解析、4 个 Figma 配方只解析不执行、10 个本地文档链接通过；56 个根 ID 唯一，差异空白检查通过。没有执行应用代码。
