## 业务边界

服务表不能将 HTTP 探针成功等同于数据库和全部功能健康。迁移仅提供账本、校验和、执行记录与异常诊断；不设计任意 SQL 控制台或无条件回滚。发布先核对目标环境、构件、备份证据、权限与审批，当前确认按钮保持不可执行。审计只展示脱敏摘要，不放密钥、原始身份材料或完整请求体。

| Summary item | `794:69` | `Label` / `Value`，详情面板复用 |

14稿均为1440×1000，8个导航项与页头／侧栏复用工作台外壳。后续实施应把表格、工具栏、提示和详情布局抽成公共结构，按页面数据组合；不每页复制外壳，不把设计截图嵌入产品。

134条显式原型跳转覆盖侧栏主导航、发布记录→核对→确认→补齐、异常撤销worker→详情→关联事件、事件队列→处理、环境→未连接、角色→访问受限及返回路径。仅把有对应示例编号的行连到详情；其他筛选、输入及非代表列表行是界面设计，未仿真数据逻辑。发布按钮没有执行动作，确认页也保持禁用。
