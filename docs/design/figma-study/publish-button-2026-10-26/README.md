# Web 导航发布按钮设计

2026-10-26，用户要求先在现有 Figma 设计中重新设计截图所示发布按钮。

- 范围：单一 Web 导航发布组件、原稿中的对应实例及局部评审；不修改手机／平板／Desktop 或业务源码。
- 当前方案（用户评审修订）：48px 点击区内置 40px 高的完整药丸，圆角绑定 `radius/999`，左右为半圆；20px 白圈加号，14px Noto Sans SC Medium 文字，8px 图文间距。复用当前 Friendly 按钮色与已有语义变量，不改变原型业务目标。
- 验收：默认／悬停／按下／焦点／不可用组件状态、实例尺寸、原有跳转、字体／变量及最终 Figma 截图。
- 已完成：[Figma 评审板](https://www.figma.com/design/3OFOC3vu18Kx9sRPjummOC/MND?node-id=818-17528)、[社区空态原稿](https://www.figma.com/design/3OFOC3vu18Kx9sRPjummOC/MND?node-id=311-31)。当前主组件集 `829:21` 位于现有规范与组件页，五状态使用同一 Label 属性；按下状态视觉高度 38px，其余 40px，点击区均 104×48。原 `812:17553` 为首轮版本，已注明被替代。
- 已应用 749 个真实 Web 顶部发布入口：565 个直接实例、184 个原框架内的实例；保留根节点 ID。发现的另一个节点是“发布与素材”栏目文字，已排除。
- 首轮结构回读：749 个入口的主组件、尺寸、圆角、加号、文字字体／字号与目标检查无剩余发现。首轮直接赋值主组件重置的 551 条发布类型点击动作已恢复；最终 737 个入口有原型动作，12 个原无动作的入口继续保留空动作。未播放原型，不把静态链接检查当运行验收。
- 本轮修订：五状态均采用完整药丸与既有 circle-plus SVG（白色描边；不可用状态为禁用色）。749个Web入口分批 `swapComponent`，749次原型动作前后相等、无需补写；圆角999／白圈图标三路径检查无发现。评审板的导航及五状态同步，放大PNG已查看。此前主组件直接变更超时，经只读与截图确认未保存后改为新组件分批同步。
- 视觉检查：社区空态截图与评审板已查看；评审板明确绑定 V2 默认浅色 `56:0`，修正后的截图为最终检查。评审板 76 个后代均为可编辑文字、框架、实例与矢量，没有图片填充；字体为 Noto Sans SC／Manrope。沿用现有按钮颜色、间距和圆角变量；未修改全局通用按钮主组件。
- 节点清单：[inventory.json](inventory.json)；当前修订证据：[revision-pill.json](revision-pill.json)；[validation.json](validation.json)为首轮16px圆角／纯加号的历史证据。全 Web 大画布切换曾使工具连接关闭，随后使用组件页上下文和精确节点更新；超限只读清单已改为紧凑清单，没有据超时推断完成。
