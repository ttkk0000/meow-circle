# M&D 晒宠、互动、私信与群聊设计计划

## 最新范围：图文宠物日记优先

2026-10-16 用户明确：首版暂不支持视频，后续再做。首版设计范围为文字、多图、评论／回复、点赞与共用表情；视频上传、播放、转码、封面处理、视频消息和自动播放均不进入本期，不显示不可用占位入口，领养核验也不以 App 内视频上传为必经步骤。表情包先采用静态图片是实施建议，GIF／动图另行扩展。图片后续应有压缩、缩略图、按需加载与上传容量保护，具体参数待实施评审；不因此限制用户可建立的宠物数量。

已记录的新需求：每个用户可建立多只宠物且不设人为数量上限；每宠独立资料页与持续日记；宠物资料、单条日记分别设置可见性；帖子、评论、领养交流、私信、群聊共用表情面板。界面名称建议为“宠物日记／成长记录”，Vlog 仅描述用户想要的记录方式，不代表首版视频能力。宠物资料私密时是否允许单条日记公开、受邀维护人员权限仍待确认；尚未制作这些扩展界面。

本轮仅落实用户已明确的视频延期和现有图文入口文案，不据此提前确定上述待确认权限，也不开始应用代码。
