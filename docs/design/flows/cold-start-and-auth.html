01 来源 → 有效内容

编辑内容打底，伙伴授权供给，获准采集辅助。先质量，再数量。

  1. 建立武汉／上海来源清单

    原作者投稿、组织协作、获准 API／页面；记录使用范围与撤回渠道。

    依据不明确：不采集、不上线，不通过大量搬运制造活跃。

  2. 最小提取与重复候选

    保留原发布时间、城市与来源；照片单独核对许可；隐私不进入公开字段。

    相似图片／地点只能提示重复，不能自动判断同一宠物。

  3. 审核时间、区域与公开精度

    不补猜时间和坐标。仅区级就标区级；原作者关系与事件状态分别核对。

    地址重名、归属争议、来源撤回：补充或隐藏，不能假装已核实。

  4. 进入对应城市列表／地图

    来源标签、最后确认、事件时间始终可见。抓取检查不能刷新事件时间。

    真实空态：可扩大区域、看指南或发布求助，不混入演示案例。

  5. 持续维护与退出

    仍在寻找、可能匹配、已找回、已结束、待更新分开。过期不自动变找回。

    撤回／删除：同步自有列表、地图、搜索和缓存，保留受控处理记录。

02 列表 → 地图 → 线索

看事件位置不必先交出自己的位置。地点、时间与来源一起阅读。

  1. 手动选择城市与筛选

    武汉／上海、区域、物种、事件类型、时间；记住选择，不静默跨城。

    无 GPS 权限：仍可选城、筛选、读案例。

  2. 点卡片中的位置摘要

    定位到同一事件的公开范围；保留原列表位置、筛选与所选案例。

    只有行政区／存疑地点：显示范围或文字，不造精确针点。

  3. 查看事件卡与对应时刻

    区分走失点、拾获点、目击点；不连接未经确认的线索生成移动轨迹。

    地图加载失败：回文字列表；网络失败不解释为“没有走失宠物”。

  4. 选择查看原文或补充线索

    原文链接公开可读；私密目击需登录。第三方地图仅收到公开地点与中性标签。

    “定位我”单独询问前台权限，不后台追踪。

  5. 审核候选，维护主案例

    目击是独立私密记录，不自动覆盖主位置；认领要另核对归属，交接重视安全。

    结束后退活跃地图和提醒；找回故事另行授权，不永久公开家庭位置。

03 浏览 → 动作 → 登录恢复

先看到价值，再要求身份。账号认证不等于宠物归属认证。

  1. 游客先看内容与公开地图

    不先索取手机号、定位、相册或推送权限，提供“先逛逛”。

    隐私投诉／撤回请求保留无需注册的安全入口。

  2. 发布／私信／私密线索触发认证

    保存站内目标与必要草稿。身份、定位、通知授权分别处理。

    取消登录：回原内容；不丢阅读位置、不把草稿公开。

  3. 登录方式与同一账号

    账号名／邮箱／手机号＋密码、邮箱验证码或已绑定微信／QQ／Apple。新身份明确创建或验证后关联，不恢复短信自动建号。

    普通登录免强制短信；失败不覆盖原标识与资料，协议默认不勾选。

  4. 年龄与交流资格

    年满14岁可交流，未满14需监护核对授权；商业发布与线下签约由成年人办理。对外交流再检查当前手机号有效验证及业务权限。

    监护、年龄、手机资格分别判断；取消／失效保留浏览和私有草稿。

  5. 恢复原页面，用户再次确认

    恢复具体宠物／案例与表单，不自动提交、发送、付款或订阅。

    返回目标只允许合法站内位置，防止跳往外部钓鱼页面。

  6. 在需要时逐项授权

    发图用照片选择器；定位我才申请定位；订阅区域提醒才申请通知。

    退出清理私密缓存；换号、注销和绑定等高风险操作再验证。

04 领养核验 → 举报复核

核对具体事项，不发笼统“真实领养”勋章；投诉不是人气投票。

  1. 说明谁在送养、谁在照护

    身份联系、宠物关系、健康已知／未知、全部必付费用、条件与责任分别填写。

    待补材料先保存；紧急求助独立标记，不冒充已核验领养。

  2. 分项核对与有限结论

    视频／人工见证支持近期接触；授权与医疗材料分别核对。展示方法、日期和适用范围。

    近期视频不证明所有权或健康；无医疗记录可如实标未知，不造健康认证。

  3. 公示范围，持续维护

    真实性说明可展开；状态过期、关系变化和费用变化重确认。正常案例继续维护；发现问题才进入举报。

    健康未知、个人／商家身份、一次无法判断，均不直接等于欺骗。

  4. 关联快照，接收并分流

    用户指出哪项不符，证据可后补。无预约码也能举报；隐私等高风险先做必要保护。

    收到回执不等于人工核实；举报人数不自动封号，截图不自动证明事实。

  5. 比较依据，回应与申诉

    独立核对版本和双方说明；结论为某项不符、未获支持或无法判断。处置与风险相称，保留改判理由。

    恢复须达到对应门槛；用抽检、响应时长、申诉改判与重复问题检验机制，不追求低举报量。

落地前必须保留的边界

  • 本人发布、授权转载、外部线索和学习示例不能混淆；学习示例不进生产地图。
  • 有联系方式不证明归属；上传材料不等于确认来源；审核通过不等于健康或找回保证。
  • 首阶段可先做列表与地图外跳，再增加内置多点地图；两城分别满足来源与维护条件。
  • 公开隐私范围必须由接口落实；不能只遮 UI，却让 URL、推送或分享暴露精确位置。
  • 当前没有实际采集、地图／短信接入或 Figma 新屏；不代表代码已经实现。
