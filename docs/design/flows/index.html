找猫用户旅程

看清具体猫、主体关系、地点与完整费用，再决定是否赴约；每一步都可退出。

文字等价流程 · 窄屏也可完整阅读
  1. 买家查看单猫详情，确认出售或有偿转让性质、猫的身份与可预约状态。
  2. 核对发布方、照护方、代理、接待方、地点类型、核验范围及完整费用；不充分可咨询或退出。
  3. 双方明确确认同一个预约快照，之后才成为已确认预约。
  4. 关键安排变化生成新版本；接受、拒绝或保持待确认，拒绝不计无故失约。
  5. 到访后按猫、身份、地点与费用分别反馈一致、不一致或不确定；未成交也可反馈。
  6. 双方可选择另行确认交接；不符时可退出并举报。

买家无需填写领养申请表。

平台没有见证的到访、付款或健康事实，不能以平台已核验表述。

发布方与材料审核

核对适用主体与授权，披露每只猫的实际关系；商家和代理不会因身份被一概拒绝。

节点说明

文字等价流程 · 窄屏也可完整阅读
  1. 发布者提交适用主体及发布、接待等授权；商家、猫舍和公开关系的代理均可参与。
  2. 建立每只猫的档案，明确领养或商业性质，披露照护、来源、接待、预计收款、责任和费用。
  3. 平台逐项审阅材料，记录对象、事项、方法、时间和版本。
  4. 缺项可补充或撤回；有据风险可暂停并提供复核申诉。
  5. 通过适用审核后发布脱敏摘要；关键变化或证据过期重新核验，历史预约不被覆盖。

私人地址和商业主体依法需公示的信息分别处理。

多账号、多个品种、定位或图片相似只能触发复核，不能直接定罪。

预约关键变更

待确认变更期间旧安排暂停；新安排或恢复原安排，均须双方明确确认。

节点说明

选择图中任一节点

点击节点，或使用 Tab 聚焦后按 Enter / 空格，查看角色、确认点和证据边界。

文字等价流程 · 窄屏也可完整阅读
  1. 系统保留已确认 v1，记录双方当时接受的猫、主体、地点、费用及责任。
  2. 任一方提出关键变更，生成 v2 并进入待确认；旧安排暂停生效。变化包括健康声明和交接、售后责任。
  3. 逐项显示旧值与新值，双方各自明确接受、拒绝或改约。
  4. 只有双方接受同一 v2，才确认新安排。
  5. 拒绝可取消或举报，不计无故失约；未回复超过明确截止时间标为 expired，不恢复旧地址。恢复原安排同样需双方重新确认。

合法第三地点见猫可以接受，关键是提前披露、说明关系并获双方确认。

买家现场主动换猫也须建立新猫关联记录，不能覆盖原猫历史。

领养旅程

领养申请独立于买猫预约；试养可选，双方交接与长期回访分别留记录。

文字等价流程 · 窄屏也可完整阅读
  1. 领养人查看要求、透明支出和隐私用途后提交必要申请。
  2. 救助方沟通适配情况，必要时补充；申请人可撤回，双方可结束不匹配申请。
  3. 双方确认约见的猫、接待方、时间、地点和关系，变更时重新确认。
  4. 试养可选：安排时确认照护期限与退出承接；也可直接进入交接。
  5. 双方明确确认交接；单方自报不能直接算成功。
  6. 30天回访形成领养结果；异常联系原救助方与平台，公开故事另行授权。

试养失败可重新匹配，不能强行推进为已安家。

回访是业务记录；不能因用户不愿公开家庭故事而判定回访失败。

举报、复核与申诉

投诉资格与公开评价依据分开；缺少预约码仍可受理，结论按证据区分。

文字等价流程 · 窄屏也可完整阅读
  1. 用户按不符类别举报；没有预约码、未成交也可受理。
  2. 平台创建待核实编号，按必要程度采取临时措施并说明原因。
  3. 授权人员比较声明、材料、历史版本与双方说明，保护身份资料和地址。
  4. 结论分为报告获支持、未获支持、无法判断；未获支持不等于证明没有欺骗。
  5. 通知双方具体理由、处置与依据；公开信息需脱敏。
  6. 当事方可申诉和补证，复核维持或改判，保留审计并同步纠正相关标签。

举报量和单方陈述不直接产生骗子标签。

到访码只是关联线索；评价依据等级不能成为拒绝投诉的门槛。

核验能证明什么

每个结论都有对象、范围、时间与版本；材料不跨越到它没有证明的事实。

节点说明

文字等价流程 · 窄屏也可完整阅读
  1. 主体：账号与所核对主体材料相符；不证明猫的所有权。
  2. 授权：发布或接待的具体权限已核对；不证明任何后续代售关系。
  3. 近期视频：支持近期能接触所示猫与环境；不证明来源、无中介、所有权或健康。
  4. 场所：材料支持所声明地点及关系；不等于平台实地巡检，照护与看猫地点可以不同。
  5. 医疗：上传仅说明有文件；向出具方确认仅支持该材料，不保证当前或未来无病。
  6. 过期、撤权或关键变化后，标明影响并重新复核；必要时限制新增预约。

每个结论至少带对象、事项、方法、时间、来源、有效状态和版本。

没有任何单项证据能导出全局真实、无中介或健康保证。
