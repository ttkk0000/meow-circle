## 7. 推荐协作安排

以下为建议分工，不表示已启动代理：

| 角色 | 负责 | 避免 |

| Gemini Android分支 | A02／A03／A04，按一个F功能逐批接入 | 修改共享DTO、全局Gradle或iOS文件 |
| iOS负责人（可为Gemini或Codex） | I01–I04，iPhone与iPad分别验收 | 继续扩充旧Swift业务Store形成双状态机 |
| Web／Desktop负责人 | W或D任务，依赖冻结F合同 | 复制KMP业务状态成不一致的规则或借用ops接口 |

人手少时按上述角色顺序串行完成即可，不强制多代理。本次不自动新建聊天、工作树或联系Gemini。
