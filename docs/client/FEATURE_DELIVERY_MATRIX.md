## 2. 各功能的实现与验收细则

### F00 启动与导航

共享：会话状态、账号 epoch、白名单目的地、草稿引用、返回后重新读资源。公开浏览不强制登录；退出后回游客，不把缓存用户当认证成功。

UI：手机按当前五个主任务导航，发布为动作入口；三种旧 AppMode 不再成为新用户前置选择。Android 返回、iOS 手势、Web back / forward、桌面返回分别维护正确栈。

验收：冷启动深链接、登录取消、页面已撤回、权限变化、切账号、旋转／分屏后仍定位同一对象。登录成功只恢复任务，不自动重放发布或确认。

### F01 登录、关联与账号安全

共享：依据[2026-10-20认证规则](../design/MND_MOBILE_AUTH_PLAN.md)，三种唯一登录标识指向稳定user_id；账号名／邮箱／手机号＋密码及邮箱验证码，普通登录不强制短信；已登录与当前手机号已验证为独立状态。保留purpose明确的OTP、倒计时、accept_terms、OAuth state / nonce交易、重复回调去重、首次建号／关联、refresh协调、安全变更后会话失效与单次reauth grant。邮箱与交流关卡依赖B04，不把现有phone自动建号接口当成新合同。

Android／iOS各自连接官方SDK；iOS Apple用系统授权和官方允许的按钮样式。客户端没有供应商secret。各端只开放capabilities与已实现合同支持的渠道，不冒用手机SDK身份，不在邮箱服务尚未接入时显示虚假发送成功。

必需状态：输入错误、验证码不符／过期／频控、供应商不可用／未安装／取消、回跳丢失、绑定冲突、已有账号关联、恢复、换号、解绑最后一种方式保护、退出当前／全部会话、注销处理中／失败／结果。

验收：未同意协议不可创建账号；三种标识登录同一user_id，标准化冲突和并发绑定不夺号；未验证邮箱不可作为登录标识，同昵称／第三方返回邮箱不自动合并；未验证手机可正常登录但不能绕过发布／评论／消息等服务端关卡，验证后不逐条短信；换号失败保留原绑定，成功后旧号不能登录原账号；两个并发401仅一次刷新；刷新后账号未串用；重复SDK回调不重复建号；敏感确认过期需重新取得grant，验证成功不自动发布原草稿。

### F02 社区与互动

共享：公开／关注／同城筛选参数、分页、详情、评论回复、目标 liked、批量指标；未知数据不能展示为真实计数。帖子修改／删除根据权限和 version。

UI：图片主导、标题换行、互动区对齐、骨架／空态／失败／离线来源。手机两列只是基准，列数由可用内容宽度和文字大小决定。

验收：空页但 next_cursor 非0继续；连续切换过滤取消旧请求；评论失败保留输入和幂等键；删除后计数重读；失权内容与图片一起移除；v2失败不静默回退静态演示。

### F03 好友与宠友圈

共享：未确认／待处理／已接受关系，申请／接受／拒绝／撤回／解除／拉黑；受众 private/public/friends/selected/excluded 与 community/circle/diary 分开表达。

UI：关注与好友分开；未确认资料不展示好友后权限；每条日记清楚表达当前可见范围。选择／排除好友改变后显示新范围，不能自动放宽为公开。

验收：解除好友后重新读圈子失败并清理缓存；转发链接不扩大权限；账号A草稿受众不会套给账号B；多面板预览不暗中提交关系变更。

### F04 多宠物、我的与协作

共享：宠物身份、物种、公开／私密档案、日记归属和协作角色。介绍协作者仅维护授权介绍／照片／答疑；领养后的照护协作者仅访问授权近况。

UI：切换宠物不串图片／草稿／日记范围；角色标签不成为全 App 工作模式。默认主题按设计，不展示旧主题选择器，保留历史偏好参考。

验收：撤销邀请／移除角色后立即收起动作并重新校验；介绍协作者不能批准领养；照护协作者不能改宠物公开资料；切宠物或账号后旧异步结果不覆盖当前页。

### F05 私信与消息请求

共享：请求状态、会话上下文、游标、clientMessageId、服务器ID、发送进度、显式已读；每次重试复用原幂等键。陌生人接受前按服务端限制仅允许一条文字，不开放图片。

UI：输入／发送／失败／重试独立，表情选择不触发发送。桌面三栏、平板竖屏两栏、手机单会话；有新消息但用户阅读旧位置时不强拉到底。

验收：回复乱序可去重，切会话旧结果不串入；前后台与弱网不重复发送；隐藏详情面板不把会话标已读；未读徽标保持居中，零未读隐藏；服务未接通不填设计里的12／3等数字。

### F06 群聊

共享：成员角色、邀请、公告、静音、退出、群主转让的发起／接受／拒绝／撤回／过期、解散独立状态；真实权限来自当前成员关系。

UI：普通成员、管理者、原群主、接收者分别呈现动作；转让和解散使用不同确认；群被解散或移除后停止发送并解释原因。

验收：成员缓存失效后不可继续读私密媒体；转让完成后原群主不保留群主操作；拒绝／撤回／超时不隐式交接；解散重试必须明确结果，不因网络失败重复危险动作。

### F07 领养

共享：申请草稿／摘要、补充、通过／拒绝／撤回、可选试养双方确认、双方交接、照护更新、支持与退养请求。服务端作为状态机真相。

UI：介绍与实际声明分开；申请只共享必要摘要；不要求上传身份证作普通表单前提；照护更新为私密；退出／撤回路径保留。

验收：单方确认不显示交接完成；重复提交不重复申请；资料变更／暂停／过期收起旧动作；试养拒绝不被视为完成领养；30天是设计的照护阶段，实际可访问期与服务状态一致，不能仅客户端定时隐藏数据。

### F08 预约

共享：`effectiveVersion` 与 `pendingProposal` 分开，历史只读。提出新版本时保留原有效安排；新提案是否生效由双方对同一版本确认决定。V1有效而V2仅待确认时，拒绝／撤回／过期仍保留V1，不生成V3；V2已生效后再恢复历史V1时间才生成V3，不复活旧V1。安全暂停不能靠撤回或过期解除。

UI：展示变更差异、双方确认状态、时间／地点／接待方／宠物／费用；普通改约保留原有效版本，具体安全关键事件使用safety_hold并明确不要按原安排出发。解除需核对并双方确认新版本；聊天里的新地址不能覆盖预约快照。年龄、单宠独占试养／候补、安全接回、游客受理与数据期限按[安全合同](../design/MND_SAFETY_AND_LIFECYCLE_SPEC.md)，这些新增合同尚未由现有API保证。

验收：两端同时变更触发409后重读；收到提案不自动确认；拒绝／撤回提案不丢原有效版本；预约版本变化后旧确认按钮无效；时区与日期跨天显示正确。

### F09 走失、拾获、线索与认领

共享：lost/found、自己宠物私有状态与公开案例、事件时间／维护时间、城市、粗公开地点、精确私密线索、证据、匹配、争议、双方交接与结束。

UI：目击线索与所有权认领分入口，材料不公开；附近提醒主动选择5–100km及频率。没有定位／地图权限时可手动选择城市并使用列表。

验收：匹配不代表所有权确认；单方“找回”不能跳过双方交接；关闭公开求助后保留所需历史访问规则；不把坐标精度不足的数据交给系统导航；不自动持续后台定位。

### F10 图文、媒体与草稿

共享：schema版本、用途、账号、基准版本、受众、有序媒体队列、单文件状态和幂等键。媒体 scope 和内容目标匹配，不允许私密材料直接挂公开内容。

UI：选图、转换、上传进度、部分失败／重试／移除、排序、返回表单和恢复。各平台控制实际句柄、临时文件与权限。图文首版不出现可用的视频入口。

验收：9张上限、10MiB／20MP、JPEG／PNG规则；HEIC可控转换；进程／页面恢复；取消后核实上传结果；失败不清空成功图片；退出账号清理私密临时文件；本机草稿和云端同步状态明确区分。

### F11 表情与贴纸

共享：目录ID、完整Unicode、24张贴纸稳定ID、收藏／最近、版本与失败恢复。编辑器的光标和组合输入由平台持有。

UI：评论、私信、群聊与日记一致；底部／侧边面板由可用空间决定。外接键盘、系统键盘和表情面板切换保持草稿，不把键盘占位写死。

验收：连续插入、选区替换、移动光标、整颗删除、取消收藏、多个最近项、肤色／旗帜／ZWJ序列、中文输入法组合区。128／24是当前素材目录规模，不是运行验收指标。

### F12 通知与附近提醒

共享：按[全局未读设计](../design/MND_GLOBAL_UNREAD_SPEC.md)保存真实计数，应用内0隐藏、1–99原数、100以上99+。聊天／互动／通知去重汇总；消息请求未读与待接受分开，群@不重复计数。保留分类偏好、频率、显式已读与账号缓存隔离；附近订阅与一般系统通知许可分开。免打扰汇总策略为待确认设计建议，服务端新语义尚未实现。

UI：采用[8张手机状态、角标边界和四端入口对照](../design/figma-study/GLOBAL_UNREAD_HANDOFF_2026_10_20.md)。进入中心不清空全部未读；回复／群聊定位首条未读；全局全部已读确认含免打扰，但不接受申请或确认预约。0、离线、失败、上次同步与待处理分别显示。未授予系统权限仍能读站内消息；拒绝后不循环弹窗。通知点击经路由和权限检查，不直接信任载荷中的私密数据或过期确认动作。

验收：GET不清未读；0／1／99／100／999边界正确且保留真实数；汇总与列表一致、不重复累计消息请求／群提及／推送副本；请求已读仍可待接受；全部已读只核销确认时快照，新消息仍未读；失败不归零、账号切换不串数据、跨设备旧回执不增加未读。附近订阅范围变更需明确保存；系统权限撤销后仍准确反映设置；没有真实APNs／Android通道时系统推送与系统图标角标标未验证，不标已送达。

### F13 核实、举报与申诉

共享：材料用途、版本、到期、待补充、结论引用、异议／申诉上下文、到访反馈各项 match/mismatch/unknown。客户端不推断真假或所有权。

UI：逐项声明“已上传／已核实／未核实／过期”，不能变成统一保证章；私密材料权限独立。未登录安全／隐私报告必须有真实后端通道后才能标完成。

验收：过期材料不能继续显示有效核实；申诉绑定原结论；普通用户不能触达 ops/admin 凭据；投诉失败保留输入但保护材料；游客报告缺口作为发布阻塞项，不用设计成功页替代。

### F14 出售与到访

共享：主体与代理关系、接待／地点／来源、基础金额＋必付费用总额、预约快照和分项反馈；金额整数分。

UI：明确区别领养与有偿信息，不强调购物车、旧订单／模拟支付；家庭饲养不是可信前提，有代理也不自动违规。

验收：报价总额与明细一致；变更后双方确认新快照；未核实付款方不写已验证收款；旧 Mock支付不能出现在新生产付款入口。

## 4. 完成判定

完成一个功能至少具备：真实数据来源、正确权限／版本、可恢复提交、默认主题 UI、目标尺寸布局、异常与退出、旧数据迁移说明、匹配的自动化用例及获授权后的构建／联调／设备证据。

在尚未获运行授权时可以交付“源码与静态审查完成，运行验证待执行”，不能标整个功能已验收。没有供应商能力的分支可明确禁用并交付其他路径，但对应完整功能仍保留未验收记录。
